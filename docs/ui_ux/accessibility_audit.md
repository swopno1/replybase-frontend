# Accessibility Audit

## Color Contrast
- **Assessment:** Generally good due to dark theme, but some slate-500 on slate-900 combinations might be borderline.
- **Task:** Verify all text meets WCAG AA standards.

## Semantic Structure
- **Assessment:** Good use of `header`, `main`, `footer`, and `section` tags.
- **Improvement:** Ensure heading hierarchy (H1 -> H2 -> H3) is strictly followed across all marketing pages.

## Interactive Elements
- **Focus States:** Need more visible outlines for keyboard navigation.
- **ARIA Labels:** Ensure the mobile menu toggle has clear labels.
