# SEO Foundation Strategy

## Semantic HTML
- Ensure all pages have a single H1.
- Use H2/H3 for logical section nesting.
- Use `article` tags for blog posts.

## Metadata & Social
- Optimize `opengraph-image.png` for high click-through on social.
- Ensure unique meta descriptions for every page.
- Implement JSON-LD schema for "SoftwareApplication" and "Organization."

## Performance
- Maintain Core Web Vitals (LCP, FID, CLS) in the green.
- Use Next.js Image component for all assets.
- Minimize third-party script impact.

## Local SEO
- Focus on "UK" targeting where applicable (given the .co.uk domain and WhatsApp number).
