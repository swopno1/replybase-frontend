# AEO & GEO Strategy (AI Search Optimization)

## Goal
Optimize content for discovery by LLMs (ChatGPT, Perplexity, Claude) and generative search engines (Google SGE).

## Strategy
1. **Structured Facts:** Use clear, concise bullet points for technical specs (excellent for LLM extraction).
2. **Conversational FAQs:** Answer questions in a "What is...", "How do I..." format that matches user prompts.
3. **Semantic Breadth:** Use synonyms and related entities (e.g., "NLP," "LLM," "Customer Service Automation," "Automated Support").
4. **Authoritative Citations:** Link to high-authority sources in the blog to build the "Knowledge Graph" around ReplyBase.
5. **JSON-LD:** Heavy use of structured data to provide a machine-readable summary of the product.
