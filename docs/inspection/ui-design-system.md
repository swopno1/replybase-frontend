# UI Design System - Inspection Report

## Global Styles
- **Primary Font:** Geist Sans (Sans-serif, clean).
- **Secondary Font:** Geist Mono (Monospaced, used for technical nuances).
- **Base Radii:** Managed via `--radius` (8px/0.5rem standard).

## Color Palette (Inspected)
- Background: `#0a0a0a` (Dark).
- Foreground: `#ededed` (Light).
- Brand 1: Indigo-600 (`#4f46e5`).
- UI Surface: Slate-900 / Slate-800.

## Recommendations
- Formalize a "ReplyBase Blue" that sits between Indigo and Electric Blue to feel more "Technical/Futuristic."
- Increase vertical whitespace in the Hero section to improve premium perception.
